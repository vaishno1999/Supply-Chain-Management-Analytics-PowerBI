# Supply Chain Management Analytics Using Power BI

## 📌 Project Overview

A Summer Internship Project focused on analyzing **Supply Chain Management data using Microsoft Power BI**. The project involved data cleaning, ETL, data modeling, KPI development, and interactive dashboard creation to support data-driven business decisions.

## 🎓 Project Details

* **Project Type:** Summer Internship Project (SIP)
* **Program:** MBA
* **Organization:** LiveTechSkills, Nagpur
* **Academic Year:** 2025–2026
* **Tool:** Microsoft Power BI

## 🎯 Objectives

* Analyze procurement, inventory, logistics, and order data.
* Transform raw data into meaningful business insights.
* Develop SCM KPIs and interactive dashboards.
* Identify supply chain bottlenecks and improvement areas.
* Support data-driven decision-making.

## 🛠️ Tools & Technologies

* Power BI
* Power Query
* DAX
* Microsoft Excel
* Data Cleaning & Transformation
* Data Modeling
* Business Intelligence

## 🔄 Work Performed

* Requirement gathering
* Data collection and cleaning
* ETL using Power Query
* Star-schema data modeling
* KPI creation using DAX
* Interactive dashboard development
* Dashboard testing and validation
* Documentation and final presentation

## 📊 Key KPIs

* Order Fill Rate
* Vendor On-Time Delivery %
* Average Lead Time
* Inventory Turnover Ratio
* Logistics Cost
* Procurement Cycle Time
* Delayed Shipment %

## 💡 Key Insights

The analysis identified areas such as vendor delivery delays, inventory imbalances, logistics cost variations, procurement bottlenecks, and the need for automated reporting.
